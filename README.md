# Super Mario HD — Android Project

Готовый Android-проект игры **Super Mario HD** (все 8 миров, полноэкранный горизонтальный режим и сенсорное управление).

## Как получить готовый APK за 2 минуты (без установки Android Studio):
1. Создайте новый пустой репозиторий на [GitHub](https://github.com/new).
2. Распакуйте этот архив и загрузите все файлы и папки (включая скрытую папку `.github`) в репозиторий.
3. Перейдите во вкладку **Actions** вашего репозитория на GitHub — сборка APK запустится автоматически.
4. Через 2 минуты откройте завершенную задачу и внизу в разделе **Artifacts** скачайте **`SuperMarioHD-APK`** (внутри лежит готовый `app-debug.apk` для установки на телефон).

## Сборка локально через Android Studio:
1. Откройте папку проекта в **Android Studio**.
2. Нажмите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
